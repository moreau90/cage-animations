  The Concept: Post-Deformation Correction

  The idea is: after deformMesh() produces positions, run a correction pass that pulls vertices back toward valid mesh
  geometry. There are a few approaches, ranked by complexity:

  Approach 1: Edge-Length Preservation (simplest)

  After deformation, iterate over every mesh edge. If the deformed edge length deviates too far from the rest-pose edge
  length, push/pull both vertices to restore it.

  For each edge (v_a, v_b):
    rest_len = |v_a_rest - v_b_rest|
    cur_len  = |v_a_deformed - v_b_deformed|
    ratio = cur_len / rest_len
    if ratio > 1.3 or ratio < 0.7:
      correction = (rest_len - cur_len) / 2
      move both verts along edge by correction amount
  Repeat 3-5 iterations

  This directly prevents stretching and compression — the exact cause of dimples and distortion. Note: PBD stretch
  clamping was tried before and disabled, but I believe it was fighting against transforms that were fundamentally wrong
   (the hierarchy seam). With the hierarchy fix + PBD, the combination should work because the transforms produce a
  reasonable starting point that PBD just refines.

  Approach 2: Delta Mush (industry standard)

  Used by Pixar, Disney, Rhythm & Hues. The algorithm:

  Precompute once (at mesh load):
  1. Build mesh adjacency (which verts are connected via triangles)
  2. Laplacian-smooth the rest mesh N times → rest_smoothed
  3. Store per-vertex delta: rest_delta[i] = rest[i] - rest_smoothed[i] (the mesh DETAIL — pores, wrinkles, features)
  4. Store per-vertex local coordinate frame from neighbors

  Every frame (after deformMesh):
  1. Laplacian-smooth the deformed mesh N times → deformed_smoothed (removes all artifacts but also removes detail)
  2. Compute each vertex's rotated local frame from deformed neighbors
  3. Re-add the rest-pose detail in the rotated frame: v_final = deformed_smoothed + R_local * rest_delta

  Result: the mesh follows the animation (from smoothing) but preserves its original surface detail and topology (from
  the rotated deltas). Dimples, stretching, and compression are eliminated because the smoothing step removes them, and
  the detail re-addition only adds the ORIGINAL mesh features.
